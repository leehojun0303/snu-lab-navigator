# 사용자 확정 요구사항

- 서울대학교 전 단과대·학과를 포괄하는 교수 기반 연구실 탐색 서비스
- 연구실 홈페이지가 없어도 공식 재직 교수면 탐색 대상에 포함
- 검색 대상: 교수명 / 연구실명 / 연구분야
- 단과대 선택 후 학과 필터는 해당 단과대의 학과만 노출
- 자연어 여러 관심사를 Gemini가 해석하여 연구 적합도와 추천 이유 제공
- 상세 제목은 `교수명 / 연구실명`
- 사진은 실제 공식 사진이 있으면 표시하고 부재/실패시에만 이름 첫 글자
- 상세에는 연구분야, 논문/성과, 포스터, 모집, 구성원/동문과 공식 링크 표시
- 논문은 실제 제목을 보여주며 규정 페이지를 논문으로 오인하지 않음
- 포스터는 이미지/PDF 자체를 읽어야 하며 후보와 verified를 구분
- 확인되지 않은 값은 0/없음으로 단정하지 않음
- 상세 open마다 Gemini를 재호출하지 않고 저장된 batch 결과 우선
- 특정 교수/학과 하드코딩으로 전체 정확도를 보정하지 않음
- 수집이 어려운 경우 공식 연구실 URL을 Gemini URL Context/Search grounding에 제공하는 fallback 허용
- 자동 수집된 모든 레코드 중 가장 완성도 높은 연구실을 대표 상세 예시로 자동 선택
- 서울대학교 공적 서비스 성격을 유지하며 사적 수익화/광고를 전제로 하지 않음
