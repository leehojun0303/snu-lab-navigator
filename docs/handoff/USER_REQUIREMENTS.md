# 사용자 확정 요구사항

- 서울대학교 전 단과대·학과를 포괄하는 교수 기반 연구실 탐색 서비스
- 연구실 홈페이지가 없어도 공식 재직 교수면 탐색 대상에 포함
- 교수 roster는 학과·단과대·연구소 등 공식 출처의 합집합(UNION)으로 판단하고 한 출처 누락만으로 교수를 제외하지 않음
- 신규 교수는 공식 roster에서 발견되면 자동 추가하고, 명시적 퇴직/전임 종료 또는 모든 관련 공식 출처에서 반복 미확인된 경우에만 보수적으로 제거
- 검색 대상: 교수명 / 연구실명 / 연구분야
- 단과대 선택 후 학과 필터는 해당 단과대의 학과만 노출
- 자연어 여러 관심사를 Gemini가 해석하여 연구 적합도와 추천 이유 제공
- 상세 제목은 `교수명 / 연구실명`
- 사진은 실제 공식 사진이 있으면 표시하고 부재/실패시에만 이름 첫 글자
- 상세에는 연구분야, 논문/성과, 포스터, 모집, 구성원/동문과 공식 링크 표시
- 논문은 실제 제목을 보여주며 규정 페이지·학과 뉴스·타 교수 연구성과를 논문으로 오인하지 않음
- 모집은 해당 연구실의 현재 모집만 표시하고 일반 입학·학생지원·행정 페이지는 제외
- 구성원은 현재 구성원과 Alumni를 분리하고 박사·석사·학부연구생·기타 역할로 구분
- 포스터는 이미지/PDF 자체를 읽고 연구실 귀속이 검증된 경우에만 공개하며 후보와 verified를 구분
- 확인되지 않은 값은 0/없음으로 단정하지 않음
- 상세 open마다 Gemini를 재호출하지 않고 저장된 batch 결과 우선
- 저장된 `research_summary` / `research_topics` / `recommendation_keywords` / `recent_papers`는 검색·추천·비교에 재사용
- 특정 교수/학과 하드코딩으로 전체 정확도를 보정하지 않음
- 수집이 어려운 경우 공식 연구실 URL을 Gemini URL Context/Search grounding에 제공하는 fallback 허용
- 자동 수집된 모든 레코드 중 가장 완성도 높은 연구실을 대표 상세 예시로 자동 선택
- 관심 연구실은 즐겨찾기로 저장하고 다시 볼 수 있어야 함
- 2개 이상 연구실을 최대 4개까지 비교하고 핵심 분야·keyword·최근 논문 흐름·구성원 규모·모집 상태를 짧은 표/키워드로 비교
- AI 비교는 저장된 분석을 우선 사용하고 필요한 경우에만 Gemini 호출
- 사용자 계정은 개인정보 없이 고유 ID만 사용하며 비밀번호·이메일·전화번호·개인 Gemini API key를 요구하지 않음
- 이미 사용 중인 ID는 회원가입할 수 없고 다른 ID를 선택해야 함
- 최근 사용 ID는 브라우저에 기억하여 재입력 부담을 줄임
- 서울대학교 공적 서비스 성격을 유지하며 사적 수익화/광고를 전제로 하지 않음
